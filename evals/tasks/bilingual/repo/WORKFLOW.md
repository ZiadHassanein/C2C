# Editorial workflow

Start with a source-to-field comparison in the existing guide working copy. A named role, the museum operations editor, can supply the missing approved fee order. The plan may request this evidence but must not claim it was obtained. Hours can be drafted now. Do not publish a fee change until the approved fee order resolves it; retain the existing fee as a labeled pending-verification draft or omit the disputed future fee claim. Publication needs separate owner approval after bilingual review.
